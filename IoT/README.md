# IoT Smart Speaker with Acoustic Control and Cloud Logic

Учебный IoT-проект: умная колонка с управлением через Telegram и логикой обработки шума.

## Описание
Проект реализует архитектуру IoT-устройства с использованием MQTT и Telegram-бота.
Физическое устройство заменено программным симулятором, полностью повторяющим
поведение реального устройства.

## Архитектура
- Telegram-бот (Kotlin) — интерфейс управления
- MQTT-брокер — обмен сообщениями
- Симулятор устройства (Kotlin) — эмуляция умной колонки

### MQTT topics
- `iot/speaker/commands` — команды управления
- `iot/speaker/state` — текущее состояние устройства
- `iot/speaker/telemetry/noise` — уровень шума

## Логика работы
- Устройство работает в режимах `normal` и `night`
- В режиме `night` при превышении порога шума автоматически включается тревога
- Telegram-бот уведомляет пользователя о срабатывании тревоги
- Поддерживается запрос актуального состояния устройства

## Управление (Telegram)
- `/mode normal|night`
- `/mute on|off`
- `/alarm on|off`
- `/reset`
- `/status`

## Планируемые расширения
В рамках дальнейших этапов проекта планируется:
- замена программного симулятора на физическое IoT-устройство (Arduino / ESP32)
- подключение реального датчика шума (микрофона)
- управление звуковым модулем (динамик, сигнализация)
- настройка порогового уровня шума через Telegram
- визуализация телеметрии (InfluxDB + Grafana)

## Примечание
На текущем этапе лабораторной работы используется программная эмуляция устройства.
При наличии физического устройства симулятор может быть заменён микроконтроллером
без изменения архитектуры системы.

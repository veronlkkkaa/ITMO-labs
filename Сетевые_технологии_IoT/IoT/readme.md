## IoT Smart Speaker with Acoustic Control and Cloud Logic

Умная колонка с управлением через Telegram и логикой обработки шума.

**Стек:** Kotlin, MQTT, Telegram Bot API, Docker

> Симулятор может быть заменён реальным Arduino / ESP32 без изменения архитектуры.

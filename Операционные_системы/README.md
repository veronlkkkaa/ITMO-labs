## Лаба 4 — Файберы, корутины и HTTP-сервер

Реализация файберного рантайма с неблокирующим вводом-выводом на основе `io_uring`/селекторов.

-  **Планировщик Feedback** — очереди реализованы как отдельные структуры данных
-  **Корутины** — неблокирующий I/O под капотом, блокирующий интерфейс для файберов  
-  **HTTP-сервер** на основе файберного фреймворка — отвечает на `/hello/<name>`
-  **Бенчмарк** — сравнение файберного сервера с thread-per-request реализацией
